Über das Projekt

RED-KI Content Manager ist eine selbst entwickelte, lokal installierte Anwendung, mit der ich (Emrah Keles) eigene Inhalte verwalte, die mit Hilfe von Künstlicher Intelligenz erstellt werden. Die Anwendung dient ausschließlich der privaten Nutzung; es werden keine Dienste oder Konten für externe Personen angeboten.

Die App kommuniziert über offizielle APIs mit Drittplattformen wie TikTok und YouTube, um auf meinen eigenen Accounts geplante Inhalte zu posten.

Funktionen

📅

Planung & Scheduling

Zeitgesteuertes Veröffentlichen von Inhalten auf mehreren Plattformen.

🎨

KI-Generierung

Lokale Bild- und Textgenerierung mit eigener Hardware (ComfyUI, lokales LLM).

🔄

Multi-Plattform-API

Native Integration mit TikTok Content Posting API und YouTube Data API v3.

🏷️

KI-Kennzeichnung

Automatisches Setzen der AI-Disclosure-Flags der jeweiligen Plattformen.

🔐

OAuth-Authentifizierung

Sichere Verbindung über OAuth 2.0 (mit PKCE), Token-Refresh und Sandbox-Modus.

🗄️

Lokale Datenhaltung

Alle Inhalte und Zugangsdaten werden lokal in einer PostgreSQL-Datenbank gespeichert. Keine Cloud-Synchronisation.

So funktioniert es

  1. Verbindung zu TikTok / YouTube über OAuth 2.0 (mit Sandbox-Modus für Tests)
  2. KI-Inhalte werden lokal generiert oder importiert
  3. Captions, Titel und Veröffentlichungszeitpunkt werden festgelegt
  4. Ein interner Scheduler postet die Inhalte zum geplanten Zeitpunkt über die offiziellen APIs
  5. Alle Posts werden mit den Disclosure-Mechanismen der jeweiligen Plattform als KI-generiert markiert
